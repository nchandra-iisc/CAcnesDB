# CAcnesDB

**CAcnesDB: A database of *Cutibacterium acnes* with Integrated
Functional Insights derived from Multi-modal Genome Annotation**

CAcnesDB is a comprehensive resource for the *Cutibacterium acnes*
KPA171202 genome and proteome, integrating functional information
derived from multiple complementary sequence-, structure-, and
interaction-based analyses.

The repository provides an offline version of CAcnesDB and the
associated datasets to facilitate reproducibility, independent use, and
further analysis.

## Using CAcnesDB

The complete CAcnesDB resource is also available through the web
interface:

**CAcnesDB:**\
https://proline.biochem.iisc.ac.in/CAcnesDB/

The offline repository can be used independently of the web interface
for accessing the annotation datasets and performing downstream
analyses.

## Reproducibility and data use

The offline version of CAcnesDB is provided to facilitate
reproducibility and independent use of the database-associated datasets.
Please retain the original file organization and metadata when
redistributing or reusing the datasets where possible.

For questions regarding the database, datasets, or their use, please
refer to the CAcnesDB project repository and the associated publication.
